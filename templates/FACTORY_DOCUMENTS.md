# Document drafting molds (English originals)

Use <!-- PAGE 1 --> etc. with meaningful logical page boundaries. Every assertion/citation must connect to blueprint annotations. These are outlines, not prefilled documents.

| Kind | Mandatory drafting content |
|---|---|
| trial_docket / appellate_docket | caption, court, case number, chronological numbered entries with filing dates, document IDs, nature of entry, orders |
| complaint / answer | jurisdiction, parties, numbered allegations/answers, claims, defenses, prayer, signatures |
| indictment | court/caption, counts, elements, time/place, statute, signatures; no invented real defendant |
| motion / opposition / reply | relief, factual statement, preserved objections, record cites, governing authority, application, declaration/exhibits, certificate |
| exhibit | original business/technical record, author, date, provenance, units, attachments as applicable |
| affidavit / deposition | identity, oath, personal knowledge, numbered paragraphs or Q/A, exhibits, certification; distinguish recollection and inference |
| trial / suppression / sentencing transcript | appearances, session dates, oath, direct/cross/redirect, objections/rulings, exhibit admission, reporter certification; do not invent testimony outside event/knowledge ledger |
| trial_order | jurisdiction, procedural posture, findings or assumed facts consistent with review standard, analysis, disposition and signature |
| verdict / judgment | actual lower-court disposition, counts/claims, relief, entry date, signature; no appellate conclusion |
| notice_appeal | parties appealing, specified judgment/order, destination court, signature/service |
| er_volume / ser_volume / fer_volume | copied filed lower pages, exact page map; index and actual local format review |
| opening_brief | disclosure if required, contents/authorities, jurisdiction, issues, statement, summary, standard of review, legal argument, precise relief, certificates |
| answering_brief | required front matter, disputed corrections, argument for each issue, response to opening authorities, relief, certificates |
| reply_brief | answer opposing argument without new issues, required tables/argument/conclusion/certificate |
| world_evidence | nonfiled record, never appellate evidence until lawful inclusion |
