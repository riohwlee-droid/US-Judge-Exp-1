## 사용자 선택 이후 필요한 제작

1. 가상 플레이 인물, 시작 법원/직무, 게임 날짜 확정.
2. 해당 법원의 조직·관할·절차·상소·지역규칙·인사·직원·의견서 관행 조사.
3. 가상 동료·직원의 지속 프로필과 관계 초기화.
4. 서로 다른 업무를 가진 첫 사건군의 전체 원문을 분할 제작·교차 검사.
5. 첫 배당/심리/저장/새 대화 복원으로 실제 플레이 검증.
6. 다음 법원으로 이동할 때 동일한 실질 조사·기록 제작을 반복.

공석·임용·선거 엔진, 여러 사건의 자동 배당, 항소·재심리/판결 종결 전이, 후속 선례 인용 탐색, 인물 관계 변경의 전용 이벤트는 후속 구현 대상이다. 기존 장부를 무리하게 수정하는 대신 버전 있는 새 이벤트와 검증을 추가한다.
