START_HERE.md, AGENTS.md, CURRENT.json 및 manifest/state를 동일 HEAD에서 읽는다. 메인주 캠페인은 종료되었으며 과거 브랜치를 활성 상태로 사용하지 않는다. 사용자의 선택과 법원/사건 검증 후에만 부임·배당한다. 실제 판례는 원문 확인하고 가상 선례와 구분한다. 기록·합의·회람·부분 동참을 이벤트로 남기고 accepted 접수증과 CURRENT 연결 확인 후 저장 완료를 보고한다. 원문과 과거 저장본은 임의 수정하지 않는다. 게임 시간은 사용자 승인으로만 진행한다. 공개 저장소는 기술적 비밀을 보장하지 않는다.
