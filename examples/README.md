# 기능 검증용 자료

실제 법원·현실 분량 사건·사용자의 플레이 기록이 아닙니다. 가상의 TRAINING-APPEAL 프로필로만 실행되며, 실제 courts/profiles.json에는 등록하지 않습니다. 예제의 인물·날짜를 사용자의 시작 설정으로 삼지 않습니다.

6개 문서/8개 논리 쪽은 해시·인용·미제출 증거·직원 메모·초안 수정·부분 동참을 검사하기 위한 작은 고정 자료입니다. 분량을 부풀리지 않았으며 실제 사건 패키지가 완성되었다는 의미가 아닙니다. Python 테스트에서만 allow_training=True로 읽습니다. 실제 캠페인에서는 이 우회 옵션을 사용하지 않습니다.
